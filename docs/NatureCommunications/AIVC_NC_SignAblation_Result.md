# 符号消融实验结果（exp47）

**日期**：2026-11-21
**问题**：AIVC 跨谱系增益究竟来自 OmniPath 的**符号**（激活/抑制方向）、还是仅来自**拓扑与幅度**？
**脚本**：`test_python_scripts/exp47_sign_ablation.py`（运行）、`exp47_summarize.py`（汇总）
**输出**：`test_results/exp47_sign_ablation_results.csv`、`exp47_sign_ablation_tertiles.csv`、`exp47_pred_{arm}_s{seed}.npy`

---

## 一、实验设计

同一 bundle（`rpe1_ood_bundle.npz`）、同一划分（7 谱系 → 2,016 盲测 RPE1）、同一架构、同一 ridge 锚点、同五种子（42/101/202/303/404），只替换先验矩阵 *A*：

| 臂 | 先验 | 含义 |
| :--- | :--- | :--- |
| `signed` | *A* = *A*~pos~ − *A*~neg~ | 参考组（论文所用） |
| `unsigned_abs` | *A* = \|*A*~pos~ − *A*~neg~\| | 抹掉符号，保留边与权重 |
| `unsigned_sum` | *A* = *A*~pos~ + *A*~neg~ | 两种边一律按激活处理（独立构造，用于交叉验证） |
| `none` | 因果足迹置零，保留磷酸化 | 去掉先验 |
| `neither` | 因果 + 磷酸化均置零 | 全部去除 |

## 四、关键补充：只有 30% 的扰动真正带有先验边

| 统计 | 数值 |
| :--- | :---: |
| 盲测扰动落在 3,603 基因空间内 | 1,725 / 2,016（85.6%） |
| **因果足迹非零（至少一条 OmniPath 边）** | **613 / 2,016（30.4%）** |
| 因果向量 L2 范数 | 中位 0.130，p90 0.316，max 0.471 |
| cos(signed, unsigned) 因果向量 | 均值 0.470，中位 0.870 |

因此在最有信息量的 **613 个有边扰动子集**上单独评估：

| 臂 | 有边子集（*n* = 613） | 无边子集（*n* = 1,403） |
| :--- | :---: | :---: |
| `signed` | **0.6394** | 0.5780 |
| `unsigned_abs` | **0.6416** | 0.5780 |
| `unsigned_sum` | **0.6417** | 0.5781 |
| `none` | 0.6351 | 0.5712 |
| `neither` | 0.6360 | 0.5724 |
| Linear ridge | 0.5738 | 0.4978 |

在有边子集上：
- 先验整体（有 vs 无）：0.6394 − 0.6351 = **+0.0043**（约 0.7% 相对）
- **符号（有 vs 抹掉）：0.6394 − 0.6416 = −0.0022（抹掉符号反而略高）**
- 相对 ridge 的优势：+0.065，但其中 **94% 在 `none` 臂就已存在**

两个独立的「无符号」构造（`|A|` 与 `A_pos+A_neg`）给出 0.5973 / 0.5975，相差 0.0002，说明零结果不是某一种构造的假象。

## 五、结论

1. **符号没有可检测的贡献。** 抹掉符号后，Top-20 在全集（+0.0006）、有边子集（−0.0022）、以及弱效应三分位（−0.0027）上都没有变差，方向甚至略微相反。
2. **先验整体贡献很小。** 即使完全移除 OmniPath（`none`），全集只降 0.008、有边子集只降 0.004，且这仍在种子噪声范围内（配对 SD 0.009–0.016）。
3. **相对 ridge 的主要增益不来自先验。** 0.597 vs 0.521 的 +0.076 中，`none` 臂已获得 0.591；增益真正来自共表达 + ESM-2 扰动嵌入、ridge 锚点与门控残差头。
4. **"先验拯救弱效应"这一叙事得不到支持。** 弱效应三分位上有无先验相差 0.005，有无符号相差 −0.003。

---

## 六、必须同时说明的局限

- 本 harness 非逐位复现（见第二节），绝对数值偏移 ±0.01–0.02；结论只对"臂间对比"成立。
- *n* = 5 种子，配对 SD 0.009–0.016，`none` 的 +0.008 约 0.5–0.9 SD，**不足以宣称显著**。正确表述是：**没有证据表明符号起作用，也没有证据表明先验效应大于噪声**，而非"证明先验无用"。
- 该消融只检验"先验作为 0.5×残差项注入"这一种架构。先验若改注入 ridge 锚点、或残差权重放大（0.5 → 2.0），结论可能不同。当前结果不能外推到其他注入方式。
- 仅 30% 的扰动带边，先验的影响上限被数据结构本身限制在少数样本上。

## 七、对稿件的影响与三种处理

| 方案 | 做法 | 代价 | 适用 |
| :--- | :--- | :--- | :--- |
| **A（推荐）** | 把 framing 从 "signed causal propagation" 降级为 "signalling-topology prior"；把本次零结果作为负结果写入 Results 与 Discussion | 删改 Introduction/Results 约 400 词，补 1 张消融图 | 保留诚实性，且与已有 80-pair 阴性对照一致 |
| B | 重新设计注入方式（先验进 ridge 锚点、加大残差权重、对 613 个有边扰动加权），看符号能否被"救活" | 需重跑与调参，2–5 天，结果不确定 | 若坚持"符号"卖点 |
| C | 放弃符号叙事，把重心移到两个真正有信号的发现：等数据审计（+Joung 使四个基线掉、AIVC 升）与模态对齐负迁移（−0.1216） | 需重写 Introduction 主线 | 与 A 可叠加 |

**我的判断**：A + C。理由：符号是本稿最容易被审稿人复现击穿的点，主动降级比被指出更有利；而"同数据下别人掉你升"这个结果是真信号，足以支撑一篇诚实的机制论文。
